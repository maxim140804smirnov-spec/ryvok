# Рывок

Личная система до 30 июня 2027: обратный отсчёт, план дня, фокус-таймер, голосовой ввод, отчёт коучу и напоминания в Telegram. Всё бесплатно: сайт на GitHub Pages, напоминания через GitHub Actions.

## 1. Выложить на GitHub Pages (10 минут, один раз)

1. Зарегистрируйся на github.com, если ещё нет аккаунта.
2. Справа вверху «+» → **New repository**. Имя: `ryvok`. Тип: **Public** (бесплатные Pages работают только с публичными репозиториями; твои записи туда не попадают, они хранятся на телефоне). Нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file**. Перетащи туда **всё содержимое** папки `ryvok`, включая папки `.github`, `bot` и `icons`. Внизу **Commit changes**.
   - Если папка `.github` не перетащилась, создай файл вручную: **Add file → Create new file**, имя `.github/workflows/telegram.yml`, вставь содержимое из папки.
4. **Settings → Pages** → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты сайт будет по адресу `https://ТВОЙ_ЛОГИН.github.io/ryvok/`.

## 2. Поставить на телефон

- **Android (Chrome):** открой адрес → меню ⋮ → «Установить приложение».
- **iPhone (Safari):** открой адрес → «Поделиться» → «На экран „Домой“».

Голосовой ввод: кнопка с микрофоном у каждого поля. При первом нажатии браузер спросит доступ к микрофону, разреши. Если кнопка не работает (так бывает на iPhone), нажми микрофон на клавиатуре телефона, это работает в любом поле.

## 3. Telegram-напоминания (15 минут, один раз)

1. В Telegram открой **@BotFather** → `/newbot` → придумай имя → он пришлёт **токен** (вида `123456:ABC...`). Токен никому не показывай.
2. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Имя `TG_TOKEN`, значение — токен.
3. Напиши своему новому боту в Telegram любое сообщение, например «привет».
4. В репозитории: **Actions** → слева «Telegram-напоминания» → **Run workflow** → в поле впиши `chatid` → **Run**. Открой запуск → шаг `node bot/notify.mjs` → там будет строка `chat_id: 123456789`.
5. Ещё один секрет: имя `TG_CHAT_ID`, значение — это число.
6. Там же, на вкладке **Variables** → **New repository variable**: имя `APP_URL`, значение — адрес сайта из пункта 1.5.
7. Снова **Run workflow** со словом `test`. Бот должен прислать «Бот работает».

Расписание (по Москве):

| Время | Что приходит |
|---|---|
| 07:30 ежедневно | Подъём: сколько дней осталось, план недели, подсказка по типу дня |
| 13:00 пн–сб | Проверка середины дня: есть ли фокус-минуты |
| 21:30 ежедневно | Вечерний отчёт: минимальный день, голос, файл коучу |
| 19:00 вс | Недельный разбор |

GitHub иногда запускает расписание с опозданием на 5–20 минут, это нормально. Если в репозитории 60 дней не было изменений, GitHub выключает расписание и присылает письмо: зайди в **Actions** и нажми **Enable workflow**. Время меняется в `.github/workflows/telegram.yml` (и в `BY_CRON` в `bot/notify.mjs`).

## 4. Как пользоваться каждый день

**Утром.** Открыть «Сегодня» → сделать главную задачу до телефона → нажать «Утренний блок сделан». Записать 3 главные задачи (можно голосом). Запускать таймер на каждый рабочий блок.

**Днём.** Таймер: выбрать направление → 25/50/90 мин → Старт. Сигнал прозвучит, блок запишется сам. Если работал без таймера, добавь минуты вручную.

**Вечером (5 минут).** Вкладка «Отчёт»: наговорить голосом, как прошёл день, вбить цифры → **Отправить файл** → выбрать Claude (или скачать и прикрепить в чат). Минимальный день отметится сам.

**В воскресенье.** Вкладка «Неделя»: разбор голосом → **Отправить файл недели** → поставить цели на следующую неделю.

**Раз в неделю.** «Ещё» → **Скачать копию**. Данные живут только на этом устройстве.

## Где что менять

Даты, направления, бюджеты часов, минимальный день, метрики, план по неделям и цели цикла лежат в `plan.js`. После изменения загрузи файл в репозиторий заново, и приложение обновится при следующем открытии с интернетом.

## Локальный запуск

```bash
python -m http.server 5180
```

Потом открыть http://localhost:5180
